# Codex

Инструкции проекта — в корневом [AGENTS.md](../AGENTS.md), состояние работы — в [PROGRESS.md](../PROGRESS.md).

- `config.toml` подключает Playwright MCP в видимом окне на Windows. Нужен Node 24 с `npx.cmd` в PATH; первый запуск MCP может скачать пакет.
- `agents/*.toml` — шесть проектных ролей Codex. Модель и reasoning наследуются от основной сессии. Ограничения зон в инструкциях ролей — рабочие правила, а не отдельная файловая песочница; права и MCP наследуются от основной сессии.
- Настройки проекта загружаются в доверенном репозитории. Открой эту папку в Codex и подтверди доверие, если приложение запросит его. После переноса начни новую сессию, чтобы загрузились роли и MCP.
- Проверка конфигурации: `codex mcp list` и `codex mcp get playwright`; `codex debug prompt-input` показывает инструкции и доступные роли без запуска модели. Наличие записи не подтверждает запуск сервера: в новой сессии проверь `/mcp` и открой игру через инструменты Playwright.
- Для визуальной проверки запусти `npm.cmd run dev`; для видимых e2e — `npm.cmd run e2e:headed`. Один браузерный прогон за раз, максимум 2 воркера. Если MCP недоступен, используй CLI и укажи это в отчёте.

Проверено с Codex CLI 0.168.0. Личные модели, авторизация и настройки безопасности остаются в пользовательской конфигурации.

Формат: [роли Codex](https://learn.chatgpt.com/docs/agent-configuration/subagents), [MCP](https://learn.chatgpt.com/docs/extend/mcp).
