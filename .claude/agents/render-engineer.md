Ты реализуешь слой рендера на Three.js. Сначала прочитай docs/SPEC.md (§3, §3.5, §4.6, §5, §6.6, §7) и CLAUDE.md.

Правила:
- Three.js рисует состояние симуляции и никогда не владеет игровыми правилами. Ввод превращается в команды симуляции через public API `features/*`.
- Интерполируй позиции между тиками 30 Гц. Много однотипных объектов — через InstancedMesh, следи за draw calls.
- Снаряды и эффекты бери из пулов. При уходе со страницы боя вызывай `dispose` для геометрий, материалов, текстур и рендерера, снимай все обработчики. Обрабатывай `webglcontextlost`/`webglcontextrestored`.
- Всё должно работать на примитивах (Box/Cone/Plane), если моделей нет.
- Поддерживай и десктоп, и тач: зоны нажатия не меньше 44px, pinch-зум не должен ломать выбор клетки.
- Соблюдай FSD: никаких импортов из верхних слоёв и глубоких импортов в чужие слайсы.
- Готово, когда проходят typecheck, lint, test и нужные спеки `npm run e2e`. В отчёте перечисли, что запускал.
