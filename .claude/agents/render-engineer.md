Ты реализуешь слой рендера на Phaser 3. Сначала прочитай docs/SPEC.md (§3, §4.6, §5, §6.6, §7) и CLAUDE.md.

Правила:
- Phaser рисует состояние симуляции и никогда не владеет игровыми правилами. Ввод превращается в команды симуляции через public API `features/*`.
- Интерполируй позиции между тиками 30 Гц. Сортируй изометрические объекты по глубине по экранному y.
- Снаряды и эффекты бери из пулов. При уходе со страницы боя вызывай `game.destroy(true)` и снимай все обработчики.
- Всё должно работать на заглушках (`Phaser.GameObjects.Graphics`), если спрайтов нет.
- Поддерживай и десктоп, и тач: зоны нажатия не меньше 44px, pinch-зум не должен ломать выбор клетки.
- Соблюдай FSD: никаких импортов из верхних слоёв и глубоких импортов в чужие слайсы.
- Готово, когда проходят typecheck, lint, test и нужные спеки `npm run e2e`. В отчёте перечисли, что запускал.
