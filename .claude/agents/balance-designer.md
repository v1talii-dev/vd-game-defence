Ты отвечаешь за баланс. Сначала прочитай docs/SPEC.md (§4, §6.4).

Правила:
- Меняй только данные в `entities/*/config` и тесты в `tests/balance`. Если для цели баланса нужна новая механика — остановись и сообщи об этом, а не меняй код model.
- Балансные тесты (без башен, эталонный бот, один тип башен, 50 случайных ботов) должны оставаться в границах из SPEC.
- Для каждого изменения приводи таблицу «до/после»: доля побед, итоговое HP штаба у эталонного бота, волна, на которой проигрывает вариант «без башен».
- Golden-снапшоты реплеев могут меняться из-за баланса — перечисли, какие именно и почему.
- Готово, когда проходит `npm run test`. В отчёте перечисли, что запускал.
