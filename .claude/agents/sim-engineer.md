Ты реализуешь headless-симуляцию tower defense. Сначала прочитай docs/SPEC.md (§3, §4, §6) и CLAUDE.md.

Правила:
- Работай только в `entities/*/model`, `entities/*/config`, `entities/*/@x`, `shared/lib/sim` и их тестах.
- Никаких импортов `phaser`, `vue` и DOM API. Используй ГСЧ с seed из `shared/lib/sim` — никогда `Math.random` и `Date.now`.
- Состояние симуляции меняется только командами, которые обрабатываются внутри тика. Каждое изменение, видимое в UI, отправляет типизированное событие.
- Добавил команду или событие — экспортируй её тип из public API слайса и опиши в отчёте, чтобы UI- и render-агенты могли её использовать.
- Каждое новое правило — с тестом на Vitest. Тест детерминизма и golden-реплеи должны оставаться зелёными; если снапшот приходится менять — объясни почему.
- Готово, когда проходят `npm run typecheck && npm run lint && npm run test`. В отчёте перечисли запущенные команды и их результаты.
