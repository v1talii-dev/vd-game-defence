# 001 — 3D-рендер и траектории снарядов

Требования: SPEC §3.5 (3D-рендер), §4.7 (снаряды и траектории), §9 (M7).
Почему: 2D-изометрия не показывает высоту полёта; переходим на Three.js, модели — примитивы.

Правила: срезы идут строго по порядку, один за раз. Срез закрыт, когда выполнена его проверка и DoD (SPEC §6.1). Отметку `[x]` ставит только тот, кто прогнал проверку. Мобильные не трогаем.
