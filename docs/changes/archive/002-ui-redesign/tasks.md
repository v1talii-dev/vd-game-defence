# 002 — Редизайн интерфейса: компактно и без срезанных углов

Требования: SPEC §9 (M8), разделы про UI/HUD.
Почему: срезанные углы (`clip-path`) и громоздкие панели не нравятся; нужен компактный лаконичный интерфейс, не перекрывающий поле боя. Основа — UX-анализ (аналоги: Kingdom Rush, BTD6, PvZ2, Defense Grid).

Когда: после M7 (001). Раскладка меняет размеры блоков и селекторы e2e, а якорь панели башни требует стабильных экранных координат 3D, поэтому до закрытия 001 меняем только форму (срез U1).

Правила: срезы по порядку, один за раз, `[x]` ставит тот, кто прогнал проверку. Исполнитель — `ui-engineer`. `data-testid` и ключи i18n не удаляем; подписи убираем только вместе с `aria-label`/`title`. Перед удалением текста — grep по e2e (`getByText`, `getByRole`, `hasText`). Контраст янтаря на фоне ≥ 4.5:1.

Дизайн-токены (`shared/ui`): `--r` 3px, `--r-lg` 4px, `--bw` 1px, `--ui-h` 32px (на `pointer: coarse` — 44px), `--gap`, `--pad`, `--fs-xs/sm/md/lg`, `--panel-bg` rgb(18 22 15 / 88%), `--panel-border` 1px rgb(184 154 82 / 35%). Один акцент — янтарь `--c-accent`; олива — успех/XP, красный — опасность. Russo One только для чисел HUD и заголовков; без uppercase и разрядки на кнопках; минимум 12px.

## Срезы

- [x] **U1. Токены и форма.** Токены формы, `UiButton` и `UiPanel` без `clip-path`/градиентов/толстых теней, скругление по токенам, состояния кнопок (hover, active, focus-visible, disabled, primary, danger), `clip-path` убран везде. Раскладка не меняется.
  Проверка: typecheck, lint, test; скриншоты меню и боя; e2e зелёные. (Запущен до закрытия 001: меняется только внешний вид.)
- [x] **U2. HUD.** Полоса 36px: монета+число, штаб иконка+число+бар 3px, «Волна 3/10 · 12 с» одной строкой, иконки паузы и скорости 32×32, «Старт волны» — единственная акцентная кнопка; тост — прямоугольник под полосой.
  Проверка: скриншот; e2e и a11y-подписи (`aria-label`/`title`) на месте.
- [x] **U3. Меню построек.** Узкая полоса внизу, слоты ~56×56 (touch 64): иконка, цена, hotkey в углу, название в tooltip; активный — рамка 2px, нет денег — цена красным; подтвердить/отмена — иконки.
  Проверка: скриншот; постройка кликом и по hotkey в e2e.
- [x] **U4. Панель башни.** ~200×180: шапка (иконка, название, шевроны, уровень), XP-бар 3px, статы одной строкой, сегментный переключатель приоритета, «Улучшить (цена)» и иконка продажи. Фиксированно справа под HUD.
  Проверка: скриншот; улучшение/продажа/приоритет в e2e.
- [x] **U5. Окна и меню.** Результат (~300px, звёзды 36px, затемнение 55%, две кнопки в ряд), пауза (inline-подтверждение выхода), главное меню и настройки (карточка без скоса, сворачиваемые секции), `TutorialHints`.
  Проверка: скриншоты; e2e результата/паузы.
- [x] **U6. Не перекрывать поле + touch.** Верх 36px, низ ~64px, правая панель ≤ 200px, остальное — полупрозрачное; проверка тач-размеров переопределением токенов.
  Проверка: скриншоты при разных размерах окна; ничего не закрывает центр поля.
- [ ] **U7. Панель башни у башни** — отложен (необязательный срез; M8 закрыт без него, вернуться отдельной задачей по запросу). Якорь по экранной проекции башни (`cellToScreen`), на touch — нижняя полоса над меню построек.
  Проверка: e2e при разных углах камеры.

- [x] **U8. Экран загрузки.** При открытии приложения и входе в бой виден понятный индикатор загрузки (логотип/название, полоса или спиннер, текст «Загрузка…» из `shared/i18n`), пока грузятся шрифты, чанк `three3d`, карта и первая отрисовка. Скрывается по `__game.ready` (бой) и после готовности шрифтов/роутера (меню); не мигает на быстрой загрузке (показывать, если дольше ~200 мс), токены формы из U1, без `clip-path`.
  Проверка: скриншот на замедленной сети (Playwright throttling) — индикатор виден и исчезает; e2e (`ready`, `data-testid`) не ломаются; время до интерактива не растёт. Можно делать после U2, независимо от U3–U7.
  Итог: `e2e/loading.spec.ts` (карта замедлена на 1,5 с). GLB грузятся лениво с примитивами-заглушками и экран не держат.

- [x] **U9. Удобство кликов мышью.** По UX-анализу (жалоба: после компактного редизайна неудобно кликать). `--ui-h` 36, `.sm` = `--ui-h`; панель башни 240px (≥1600 — 264), «Улучшить» flex:1 h36, приоритеты h32, «Продать» отделена gap 12px и danger-outline; слоты 60px (≥1600 — 64) gap 6, шрифты ≥12px; HUD 40px (токен `--hud-h`), пауза/скорость 36px с hit-area ::after inset -4px; `--ui-scale` 1 / 1.15 (≥1600) / 1.3 (≥2400); transition и hover на .prio/.tower. Пикинг: башни 0.8 клетки для мыши, враги 0.55 (сначала SPEC §3.5, затем pick.ts/input3d и тест).
  Проверка: скриншоты 1280×720 и 1920×1080; e2e зелёные; измеренные размеры целей ≥ заявленных.
