# S6 — воспроизводимая сборка моделей

Проверен 2026-11-16. Единый запуск и входы описаны в [tools/models/README.md](../../../tools/models/README.md): `BLENDER=<executable> npm run models:build -- --out <staging>`. Проверенная версия — Blender **5.2.3 LTS**, build `e13b728c6880`. Runner проверяет версию и входы, требует пустой каталог вне public, запускает 11 генераторов и общий verifier; ошибка Python останавливает сборку. Старые прямые Python-запуски сохраняют прежний каталог вывода, поэтому для повторяемой сборки используется runner.

Сгенерированы все **16 GLB**, включая 13 активных и 3 заготовки M14. Два независимых запуска в `tmp-shots/models-a` и `tmp-shots/models-b` прошли verifier и `--compare`. Сравнение staging с `public/assets/models` также прошло: геометрический контракт не изменился, замена public GLB не понадобилась. M14 к механике не подключён.

## Контракт и проверки

- Verifier теперь читает реальные вершины и индексы BIN, учитывает родительские TRS/matrix, проверяет bbox, узлы, pivots, цвета вершин, материалы, отсутствие текстур/скинов/анимаций, границы accessor и бюджеты. Неизвестная модель не получает безлимитный допуск. Сравнивается геометрический контракт с округлением до 1e-5, а не метаданные экспортера/байтовый хеш GLB. Покрытие runtime modelConfig и координаты визуальных дул проверяются тестом.
- Треугольники: башни 454/700, огнемёт 592; руины 240/196; техника 584/912/1276; пехота 196/220/180/220; дрон 244; декор 48/84/116. Все существующие бюджеты соблюдены. Head башен — (0,.56,0), turret танка/босса — y=.28/.34, бедро пехоты — y=.2.
- Проверка дула выявила исходное расхождение: логическая высота вылета .5 не совпадала со стволами GLB. Рендер фиксирует визуальный старт при projectileFired: MG (0,.78,.60), ракета — средняя точка четырёх торцов (0,1.155,.387), с учётом yaw, масштаба уровня и плато. Вспышка/дым/меш начинают у модели, затем визуальная поправка затухает к точке попадания. Симуляция, урон, время полёта и реплеи не менялись.
- **221 Vitest**, **6 node-тестов инструментов**, typecheck, lint и production build прошли. ESLint по существующему конфигу не проверяет tools/*.mjs; их исполняемые проверки — `models:test`. Реальные GLB через GLTFLoader проверены на замену заглушек, вращение головы отдельно от основания, неподвижный hip при качании ног и stance без фазы. Тест визуального снаряда проверяет поворот/масштаб, начало/конец и отсутствие изменения ProjectileState.
- Полный headed e2e с отдельным preview: **49 passed / 7 skipped**, код 0. Golden и баланс прошли в общем Vitest без изменения эталонов.
- Playwright MCP на dev успешно разобрал все 13 активных файлов с ожидаемыми узлами; проверена сцена с двумя башнями, шестью типами врагов и декором, после обстрела — обе модели руин. Просмотрены [модели](s6-models.png) и [руины](s6-ruins.png). Повороты и походка дополнительно проверены на реальных instance-матрицах интеграционным тестом.
- Gzip (`node:zlib.gzipSync`): initial index + waves **85 653 байта**, дополнение боя **368 035**, Rapier **1 644 885**, все JS **2 099 200**. Бюджеты 100 KiB / 400 KiB / 1,7 MiB / 2,2 MiB соблюдены.
