# S5 — переходы интерфейса GSAP

Проверен 2026-11-16. Брифинг, панель башни и окно результата используют общий `useUiTransition`: появление за 200 мс и закрытие за 150 мс. Анимируется внутреннее содержимое панели башни, поэтому её внешнее позиционирование продолжает следовать камере. Vue по-прежнему управляет выбором, исходом боя и удалением DOM.

Контексты GSAP очищаются после завершения, отмены и unmount; стили восстанавливаются. Уходящий элемент сразу становится inert и не принимает клики. При reduced motion оба перехода завершаются сразу. Фокус при появлении не переносится. Дублирующие CSS pop/fade панели и результата удалены; отдельное вращение/увеличение звёзд результата заменено общим появлением окна. Hover/focus и индикаторы прогресса сохранили существующие CSS-стили.

## Проверки

- Typecheck, lint и production build прошли; 40 файлов, **219 unit-тестов**. Общий переход проверяется на отмену, однократный callback, одновременные анимации, повторное открытие, reduced motion и очистку. Компонентные тесты брифинга и панели подтверждают сохранение фокуса/маршрута, внутренний tween и безопасное закрытие при пустом выборе.
- Полный headed e2e на отдельном preview: **48 passed / 7 skipped / 1 failed**. Единственное падение — новый тест с `speed=0`, ожидавший применения команды без шага симуляции. После добавления явных шагов все **3 целевых headed e2e прошли**. Продуктовый код после полного прогона не менялся. Покрыты быстрый возврат/повторное открытие, normal/reduced motion, клавиатура, камера с открытой панелью и повторный бой через результат.
- Playwright MCP на dev: проверены промежуточная прозрачность брифинга, сохранение фокуса кнопки «В бой», transform только внутреннего контейнера башни, восстановление стилей и окно результата. Просмотрены кадры: [брифинг](s5-briefing.png), [панель](s5-tower.png), [результат](s5-result.png).
- Gzip по `node:zlib.gzipSync`: initial index + waves **85 654 байта**; дополнение боя battle + three3d **367 805**; Rapier **1 644 885**; все JS **2 098 971**. Бюджеты 100 KiB / 400 KiB / 1,7 MiB / 2,2 MiB соблюдены.
