# S2 — качество рендера в бою

Дата: 2026-11-13. S2 завершён; следующий срез — S3.

Модуль `three/frame.ts`, выбор high/low, composer/N8AO/SMAA, сброс статистики на полный кадр и пересоздание composer после context loss уже реализованы в S1. Дополнительная обёртка не потребовалась.

Исправлены два дефекта HUD: полоски HP и шевроны больше не пишут depth и обрабатываются существующим transparency-aware путём N8AO; кольца прогресса хранят линейный цвет и используют `colorspace_fragment`, чтобы high и low выполняли одно преобразование цвета. Добавлена обработка window resize для смены DPR при неизменном CSS-размере поля, с очисткой подписки.

Проверки расширены: контракт материалов HUD и линейных цветов; framebuffer при resize; предел 150 calls в обычной сцене; context loss high/low с проверкой выбранного профиля. Quality в context-loss передаётся перед hash, поскольку рендер читает `location.search`.

Typecheck, lint, 206 unit-тестов и production build прошли. Финальный полный `npm.cmd run e2e:headed`: **43 passed / 7 skipped за 53.6 секунды**, один воркер, без падений. Пропущены 3 мобильных сценария, отключённая панель очереди и 3 opt-in PERF-теста. Финальная версия context-loss подтверждает фактический high/low; framebuffer проверяется через poll. Пороги и таймауты не ослаблялись. PERF не запускался.

Предыдущий полный headless-прогон дал 34 passed / 7 skipped / 9 failed за 7.5 минут (таймауты); все падения затем прошли в последовательном headed-прогоне. Финальный полный headed-прогон закрывает пробел единого зелёного прогона.

Визуально просмотрены скриншоты high/low на 1280×720 и 1920×1080: согласованный фон, сглаженные края в high, без заметной белёсости и ореолов возле оснований. Просмотрен кадр улучшения с панелью башни и радиусом. Скриншоты финального прогона сохранены рядом: [high 1280](s2-high-1280.png), [high 1920](s2-high-1920.png), [low 1280](s2-low-1280.png), [low 1920](s2-low-1920.png). Это обзор Chromium, а не ручная проверка всех боевых состояний. Playwright MCP в текущей сессии недоступен; использован CLI.
