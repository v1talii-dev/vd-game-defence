# S1 — минимальная интеграция единого стека

Дата: 2026-11-12. Срез не заменяет последующие S2–S7 и не означает завершение художественной переработки.

## Реализовано

- Установлены точные `postprocessing 6.39.6`, `n8ao 2.0.1`, `three.quarks 0.17.1`, `gsap 3.15.1`, `@dimforge/rapier3d-compat 0.21.0`. Three.js остаётся 0.186.1, quarks.core в lockfile — 0.17.1.
- High: один `RenderPass → N8AOPostPass → SMAA` в существующем RAF. Никакого второго игрового цикла или MSAA поверх SMAA. Low: прямой рендер без AO, MSAA и загрузки Rapier; применяется существующий DPR cap.
- `three/frame.ts` владеет composer, resize и освобождением ресурсов. `renderer.info` сбрасывается один раз перед всеми проходами кадра. N8AO требует дополнительного освобождения внутренних fullscreen-ресурсов: установленная версия не освобождает их унаследованным `Pass.dispose()`.
- Quarks заменяет только эффект завершения постройки/апгрейда: **один переиспользуемый emitter, максимум 16 частиц high / 7 low**, повторное завершение перезапускает burst вместо накопления. Остальные частицы намеренно остаются до S3. Нулевой delta останавливает частицы, масштабированное время и substeps учитывают внутренний clamp Quarks.
- Rapier инициализируется лениво только в high и создаёт один пустой World как проверку совместимости S1. Мир освобождается при выходе, поздний init не создаёт мир после dispose, ошибки не превращаются в молчаливый downgrade. Обломки и физические шаги появятся только в S4.
- GSAP: enter-only переход брифинга кампании через Vue Transition, без задержки закрытия и запуска боя. Reduced motion — немедленный конечный вид, отмена и unmount очищают context/tween и стили. Панель башни и результат — пока без миграции (S5).
- Debug `fxState` дополнен текущим quality, наличием composer, числом систем/частиц Quarks и готовностью мира Rapier; production `window.__game` отсутствует.

## Найдено и исправлено при приёмке

1. Потеря WebGL-контекста ставила постоянный `session.paused=true`, поэтому после восстановления тики не возобновлялись. Теперь локальный `lost` останавливает advance, не переписывая пользовательскую/blur-паузу; composer пересоздаётся. Регресс-сценарий проверяет остановку тиков при потере, возобновление после восстановления и сохранение ранее включённой паузы.
2. ClearPass очищал offscreen target цветом, закодированным для предыдущего screen target: фон high получал повторную gamma correction. Явный `scene.background` заставляет Three выполнить очистку в пространстве текущего target. Ручная проверка WebGL `readPixels` на пустом участке фона: high и low дают **[133, 118, 79, 255]**, то есть исходный FOG_COLOR. Карта/HUD не нуждаются во втором цветопреобразовании.

## Проверки

- Независимый QA-аудит исходников не нашёл других блокирующих S1-регрессий; браузерная приёмка выполнена основной сессией.
- Финальный код: typecheck/lint/build passed, **205 unit passed** (36 файлов), golden/балансные снапшоты не менялись.
- Полный headed e2e + PERF: **44 passed / 4 skipped / 1 failed**; единственное падение — восстановление контекста выше. Отдельная проверка исправления: **1 passed**, включая сохранение пользовательской паузы. После двух финальных исправлений повторно прошли typecheck/lint/test/build и **все 4 целевых headed e2e** (`context-loss` + `unified-stack`): WebGL, high/low, частицы/пауза/resize и reduced-motion брифинга. Второй полный e2e-прогон не выполнялся; это полный первый прогон плюс проверка исправленных/новых сценариев, а не заявление о 49 тестах в одном финальном запуске.
- Full PERF наблюдение S1: **60.116 RAF FPS**, 40 башен, 143 врага в конце, до **51 full-frame calls**; меню 104 мс, меню → бой ready 1692 мс. Стресс остаётся убывающим, как в S0: это сравнение одинакового сценария, не итоговая приёмка стабильных 150 врагов.
- Память существующего perf-теста: **21.941653 → 21.990910 MB**, WebGL **56 geometries / 18 textures / 21 calls** до и после 3 рестартов. Улучшение этого наблюдения не доказывает исправление всех прежних утечек: исходный workload пустой, S7 остаётся открыт.
- Видимый Playwright MCP на dev: high/low, выбор башни, Quarks 16/7, high Rapier ready / low false, без pageerror и console error. Скриншоты: [high](s1-high-1280x720.png), [low](s1-low-1280x720.png). Resize 1280×720 → 1920×1080 проверен новыми e2e.
- Production preview под `/vd-game-defence/`: обе сцены рисуются без ошибок, debug API отсутствует; low не запрашивает Rapier, high загружает отдельный локальный chunk, без CDN.
- LSP-пробы не вернули ошибок, но часть Vue/TS-проверок не подтвердила clean (timeout / push-only сервер); `vue-tsc` и полный ESLint выполнены отдельно, не заменены пустым диагностическим кэшем.

## Версии, лицензии и аудит

`npm ls` показывает единственный runtime Three.js 0.186.1. Дополнительный Rapier 0.12.0 находится под `@types/three`, нужен старым декларациям Three helper и не импортируется приложением. Three helper `RapierPhysics` не используется: он подтягивает CDN-версию и создаёт собственный interval.

Лицензии проверены по установленным пакетам: postprocessing — Zlib, Quarks/core — MIT, Rapier — Apache-2.0. N8AO имеет расхождение: package metadata ISC, приложенный LICENSE — CC0 1.0; сохраняем поставляемую лицензию, не объявляем пакет ISC-only. GSAP — собственная Standard “no charge” License, не MIT; проверенные условия разрешают использование в игре, ограничения касаются конкурирующих визуальных animation-builders. Ссылка: https://gsap.com/standard-license/ (проверено 2026-11-12).

`npm audit --omit=dev`: **0 vulnerabilities**. Полный audit: 17 замечаний (14 moderate, 3 high) по dev-инструментам ESLint/TS ESLint/steiger/zod/glob/minimatch/test-utils. Автоматические force-fix и посторонние обновления не выполнялись. При установке были EBADENGINE-предупреждения существующих nopt/abbrev для Node 24.14.0; фактические команды DoD работают, обновление Node отдельно при следующем обслуживании окружения.

## Размеры и бюджеты перед S2

Метод как в S0: отдельный `node:zlib.gzipSync` для каждого production JS-файла. Vite выводит немного другие gzip-числа — их не смешиваем.

| Область | Gzip bytes (пробная сборка S1) | Потолок для S2–S7 |
|---|---:|---:|
| Initial: index + waves | 85 524 | 100 KiB |
| Дополнение боя: battle + three3d | 366 883 | 400 KiB |
| Lazy high-only Rapier | 1 644 885 | 1.7 MiB |
| Все JS-файлы, включая settings и Rapier | 2 097 918 | 2.2 MiB |

Финальные исправления меняют единичные байты/имена chunks, а не порядок этих величин. Rapier — главный расход размера, он не входит в начальное меню и отсутствует в low. Это технические ограничения дальнейших срезов, **не отмена временных целей SPEC**: интерактивность desktop <3 с / mobile <5 с, итоговый 4G и реальный телефон ещё не проверены. Если бюджеты/время не выдерживаются — сначала lazy-loading и сокращение стека, не молчаливое повышение лимита.
