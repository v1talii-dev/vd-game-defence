# S3 — общий движок частиц Quarks

Дата: 2026-11-13. S3 завершён; следующий срез — S4.

Вспышки выстрела, искры попадания, взрывы, дым ракет и завершение строительства/улучшения используют один `BatchedRenderer`, общие материал, геометрию и процедурную радиальную RGBA-текстуру. Шесть постоянных систем включают пресет пламени, пока не подключённый к механике (пакет 010). Старый ручной InstancedMesh-пул с `onBeforeCompile` и отдельный `doneEffect` удалены; тела пуль, ракет и вражеских снарядов и их траектории сохранены.

Общий лимит живых частиц — 128 high / 48 low. События немедленно создают частицы в мировой позиции, не сбрасывая предыдущую вспышку. Объекты частиц переиспользуются. Low уменьшает число частиц и плотность дымного следа; во время паузы след не пополняется. Нулевой шаг обновляет GPU-буферы без старения частиц, поэтому эффекты видны и после отладочного шага на паузе. Завершение стройки отображается над башней на высоте существующего кольца прогресса, чтобы точечный эмиттер не скрывался внутри модели. Обновление получает масштабированное время из прежнего RAF и делит его на шаги до 0.1 с, сохраняя x1/x2/x8. Повторный бой создаёт чистый движок; dispose освобождает исходные и сгенерированные ресурсы, включая текстуру и материалы батча.

Учтены особенности установленного Quarks: точечный эмиттер вместо стандартной сферы радиусом 10; первоначальная регистрация батча с нулевым временем, чтобы не удваивать первый шаг живых частиц; одно преобразование выходного цвета в шейдере батча с учётом текущего render target. Частицы прозрачные, не пишут depth, дым плавно затухает.

## Проверки

- Typecheck, lint, production build прошли; unit: 36 файлов, 211 тестов. Семь тестов эффектов проверяют общий лимит high/low, повторное использование объектов, одновременные позиции, ход времени/паузу/затухание, освобождение ресурсов, прозрачность/цвет и пресет пламени.
- E2E проверяет агрегированные частицы, паузу и resize; новые high/low сценарии проверяют события выстрела, попадания, дыма, реальные руины от обстрела и перезапуск через окно результата. Счётчики принятых событий доступны только через существующий dev/test `fxState`.
- Playwright MCP доступен; dev-сцена открывалась в видимом браузере. Полный headed e2e — 45 passed / 7 skipped, один воркер. После исправления нулевого шага прошли 5 целевых e2e, на финальной версии — 5 целевых (14.3 с). Просмотрены high/low боевые кадры: видны мягкие оранжевые вспышки, нет непрозрачных дымных квадратов и перекрытия HUD. Финальные кадры паузы/resize сохранены: [high 1280](s3-high-1280.png), [high 1920](s3-high-1920.png), [low 1280](s3-low-1280.png), [low 1920](s3-low-1920.png). На паузе новый burst выглядит как небольшая светлая точка над башней: частицы ещё не разошлись; загрузка GPU-буферов при нулевом времени проверена отдельным unit-тестом.
