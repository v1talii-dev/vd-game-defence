# 006 — Каркас кампании (M12)

Требования: SPEC §3.3, §4.8, §6.4, §9 (M12); `docs/CONCEPT.md`.
Почему: игра знает один зашитый уровень (`BattlefieldView.vue:9`, `ResultDialog.vue:17`, `MainMenuPage.vue:8`, `tests/helpers/level.ts`), волны общие (`entities/wave/config/waves.ts`), сохранение v1 не готово к списку уровней. Каркас нужен до первого нового контента (M14+).

Правила: срезы по порядку, `[x]` ставит тот, кто прогнал проверку. e2e: максимум 2 воркера, один прогон за раз, один прогон на срез. git worktree не использовать. Сначала контракт данных/симуляции + тест, потом UI и рендер. Поведение `desert-base` не меняется: реплеи и балансные тесты проходят без правок снапшотов. Новых башен, врагов и карт нет — это M14+.

## Развилки (решены 2026-10-23)

- R1. Уровней в первом выпуске 5; в M12 один реальный (`desert-base`) и заглушка `stub-2` (`implemented: false`).
- R2. Разблокировки выводятся из `levels` сохранения, отдельно не хранятся.
- R3. Ключ v1 после миграции не удаляется (безопасный откат).
- R4. Маршрут боя `#/battle/:levelId`; экран кампании `#/campaign`; пункт «Играть» в меню ведёт на кампанию.
- R5. Без бесконечного режима и без влияния врагов на башни; прокачки нет.
