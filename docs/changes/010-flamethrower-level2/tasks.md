# 010 — Огнемёт «Горелка» + уровень 2 «Каменный перевал» (M14)

Номер 010, а не 009: `009` занят пакетом мобильных (M13c).

Требования: SPEC §4.2 (огонь, тяжёлая пехота), §4.3 (башня), §4.5 (враги, правило радиуса), §4.8–§4.9 (уровень, огнемёт, карта, волны), §6.4 (балансные тесты), §9 (M14); числа и обоснование — `docs/CONCEPT.md` §2–§4. Решения оркестратора по умолчанию 2026-10-23, пользователь может пересмотреть (развилки ниже).
Почему: игра с двумя башнями и одной картой не даёт второго «ощущения» — M14 вводит первую башню с новой механикой (конус и горение), два новых вида пехоты, требующих контрпика, и первый реальный уровень кампании сверх `desert-base`.

Правила: срезы по порядку, `[x]` ставит тот, кто прогнал проверку. e2e: максимум 2 воркера, один прогон за раз, только в F9 (и один смоук в F7, если стоит в плане). git worktree не использовать; Python нет (скрипты на Node.js; `tools/models/*.py` — только исходники моделей, их не трогаем, GLB готовы). Сначала контракт симуляции + тест, потом рендер и UI. Числа башни и врагов — стартовые из SPEC §4.9, итог подбирает F8. Golden-реплеи и балансные тесты `desert-base` не меняются: огнемёта и новых врагов там нет (если снапшот сдвинулся — это баг, а не повод обновить).

## Развилки (решены оркестратором по умолчанию)

- R1. Огнемёт — **мгновенный конус без снаряда** + горение 2 с, не складывается между огнемётами (проще и детерминированнее, чем облако или снаряд-огонь).
- R2. Щитоносец — **класс брони `heavy`** (матрица), без направленной защиты «спереди»: ориентация врага в симуляции не нужна.
- R3. Дальность огнемёта (2.2–2.6) меньше дальности гранатомётчика/танка/босса: исключение из правила §4.5, компенсируется HP 220/290/360 и ремонтом M13b.
- R4. Огнемёт доступен на уровне 2 сразу (`allowedTowers`), в `unlocks` — чтобы остаться доступным на следующих уровнях после первого прохождения.
- R5. `stub-2` заменяется уровнем `stone-pass`; новая заглушка `stub-3` («Седловина») сохраняет проверки «Скоро».
- R6. Бегун и щитоносец башни не атакуют (правило M13b).
- R7. Карта делается скриптом `tools/maps/build-stone-pass.mjs` (Node.js), не вручную в Tiled: путь и клетки заданы данными, скрипт сам проверяет связность и число клеток.

## Риски

- Балансные тесты и реплеи `desert-base` не должны сдвинуться: огнемёт и новые враги не встречаются на уровне 1 (`allowedTowers`, волны). Любой сдвиг — баг разбора, а не повод править снапшоты.
- Огнемёт ломает правило радиуса атаки врагов (R3): если в F8 окажется, что башню «выбивают» до окупаемости, повысить HP или дальность до 2.6–2.8, а не снимать `towerAttack` с гранатомётчика.
- Перф: конус и горение считаются на каждом тике по всем врагам в зоне — не больше 150 врагов × несколько огнемётов, умещается; пламя — один пул и один draw call.
- `stub-2` упоминается в тестах и e2e (`unlocks.test.ts`, `progressStore.test.ts`, `campaign.spec.ts`, `full-battle.spec.ts`, `level-route.spec.ts`): переименования в F3 (unit) и F9 (e2e) — не забыть.
- Конфликт по `three3d.ts`/`models.ts` с M13/M13b/M13c: см. порядок выше.
