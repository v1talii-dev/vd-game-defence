## Известные проблемы


- Перф §6.6: после инстансинга моделей/эффектов/дороги draw calls в стрессе 38 (было 129), 60 FPS, куча +7% после 3 рестартов. Размер three3d-чанка 591 КБ (gzip 152 КБ), предупреждение vite — ядро WebGLRenderer, меньше не ужать.
- Флейки e2e при полном прогоне (по разу падали build «небилдабельная клетка», smoke, blur-pause; по отдельности проходят) — разобрать qa-debugger.
- В e2e остались названия тестов с префиксом «r3d:».
- Баланс может сместиться из-за задержки урона (время полёта) — разбирать в S2.
- `HTTP_PROXY` вешает запросы к localhost в e2e.

- Звук отложен по решению пользователя: игра без звука, вернёмся отдельной задачей по запросу.
